# test-task-etolegko-pro

Консольный скрипт на Python для замера скорости скачивания.

Скрипт делает **10 последовательных запросов** к указанному адресу, на каждый
дожидается полного ответа (тело читается до конца), затем считает среднее время
запроса, общий объём скачанных данных и печатает скорость скачивания.

## Требования

- Python **3.9+**
- Внешних зависимостей нет — используется только стандартная библиотека
  (`urllib`), поэтому `pip install` не нужен.

## Запуск

```bash
git clone https://github.com/Dusmatoff/test-task-etolegko-pro.git
cd test-task-etolegko-pro
python speedtest.py <URL>
```

Пример (тестовый файл 10 МиБ):

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

> На Linux/macOS вместо `python` может понадобиться `python3`.

### Параметры

| Параметр            | По умолчанию | Описание                                  |
|---------------------|--------------|-------------------------------------------|
| `url`               | —            | Адрес для скачивания (`http://` или `https://`) |
| `-n`, `--count`     | `10`         | Количество запросов                       |
| `-t`, `--timeout`   | `30`         | Таймаут сокета в секундах                 |
| `-h`, `--help`      |              | Справка                                   |

## Пример вывода

```
Адрес: https://proof.ovh.net/files/10Mb.dat
Запросов: 10

Запрос  1:     10.49 МБ за 2.982 с
Запрос  2:     10.49 МБ за 2.977 с
...
Запрос 10:     10.49 МБ за 3.011 с

Среднее время запроса: 3.561 с
Всего скачано:         104.86 МБ (104857600 байт)
Скорость скачивания:   23.56 Мбит/с (2.94 МБ/с)
```

## Единицы измерения

- **Время** — секунды (с).
- **Объём** — десятичные единицы: 1 КБ = 1 000 байт, 1 МБ = 1 000 000 байт.
  Точное число байт печатается рядом в скобках.
- **Скорость** — основная единица **Мбит/с** (мегабиты в секунду,
  1 Мбит = 1 000 000 бит) — в ней обычно указывают скорость интернет-канала
  провайдеры и сервисы вроде speedtest. В скобках дублируется в **МБ/с**
  (мегабайты в секунду); 1 МБ/с = 8 Мбит/с.

## Как считается

- **Время запроса** — от отправки запроса до получения последнего байта тела
  ответа (включает DNS, установку TCP/TLS-соединения, ожидание ответа и
  скачивание).
- **Среднее время** = сумма времён всех запросов / число запросов.
- **Объём** — сумма байт тела ответа по всем запросам (без HTTP-заголовков).
- **Скорость** = общий объём / суммарное время всех запросов.

Чтобы получать реальный файл, а не закэшированный ответ, скрипт отправляет
заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity` (без сжатия —
считаются именно байты файла).

## Ошибки

Если сервер вернул HTTP-ошибку (4xx/5xx) или произошла сетевая ошибка,
скрипт печатает причину в stderr и завершается с кодом `1`. Неверные
аргументы — код `2`, прерывание по Ctrl+C — код `130`.
